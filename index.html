Why Build with Nexus?

Declarative control meets full Linux compatibility.

Declarative Setup

Single configuration blueprint to track packages, kernel choices, and system layout without bash script clutter.

Standard FHS

No non-standard path wrappers. Everything sits in normal /usr/bin directories so AUR and precompiled binaries work out-of-the-box.

Rust Orchestrated

CLI built in Rust using strict sysroot validation, fast SquashFS compression, and modern Limine volume pathing.

Hybrid Bootable

Outputs clean UEFI/BIOS ISOs ready for immediate QEMU testing or writing directly to a USB stick.
